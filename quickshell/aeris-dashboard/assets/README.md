# Cooling control icons

The PWM controls vendor only these assets; no desktop icon theme is required.

- Feather 4.29.2: wind, zap, cpu. MIT; see feather/LICENSE.txt.
  Source: https://github.com/feathericons/feather/tree/v4.29.2/icons.
  Strokes normalized to white and 2.5px for tinting.
- Material Design Icons 7.4.47: fan. Apache 2.0; see icons/LICENSE.txt.
  Source: https://github.com/Templarian/MaterialDesign-SVG/tree/9e04201d4557e729822fb57f62a316c3dea1d4a8.
  Fill normalized to white for tinting.

Later dashboard theme assets are maintained separately from the PWM setup.
